# FinTech Fraud Detection Platform

Plateforme de traitement de transactions bancaires avec détection de fraude, scoring de risque, et explainabilité IA.

## Architecture

- **Domain Layer**: Clean Architecture avec Event Sourcing
- **Application Layer**: Use Cases, Commands, Queries
- **Infrastructure**: PostgreSQL, Redis, Kafka, OpenSearch, Mistral
- **Interfaces**: REST API, Kafka Workers, Admin Dashboard

## Démarrage rapide

```bash
docker-compose up
```

Voir SETUP.md pour les détails.
